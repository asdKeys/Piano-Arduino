# [ARDUINO]Piano

## About
A piano made with the Arduino!

## How to Run

Download the Arduino IDE, then copy and paste the code in the file "Button_Piano.ino" into the IDE.

### Building

### Parts Needed

- any Arduino board
- any breadboard
- an active buzzer
- 5 buttons
- 19 wires
